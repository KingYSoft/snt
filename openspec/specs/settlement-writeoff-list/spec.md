## ADDED Requirements（新增需求）

### Requirement: 展示销账记录列表

系统应展示分页的销账记录列表，支持搜索和过滤功能。

#### Scenario: 查看销账列表

- **WHEN** 用户导航到销账列表页面
- **THEN** 系统在数据表格中显示销账记录，包含销账单号、公司名称、金额、币种、销账日期和状态列

#### Scenario: 搜索销账记录

- **WHEN** 用户输入搜索条件并点击搜索按钮
- **THEN** 系统根据搜索条件过滤销账列表

#### Scenario: 销账记录分页

- **WHEN** 用户点击分页控件或更改每页显示数量
- **THEN** 系统相应更新显示的销账记录

### Requirement: Mock 销账列表 API

系统应提供销账列表数据的 Mock API 端点，直到后端对接完成。

#### Scenario: 获取 Mock 销账数据

- **WHEN** 前端请求销账列表数据
- **THEN** 系统返回包含示例销账记录的 Mock 数据

### Requirement: 导航到销账创建

系统应提供按钮或操作以导航到销账创建表单。

#### Scenario: 导航到创建销账

- **WHEN** 用户点击"新增"或"新建销账"按钮
- **THEN** 系统导航到销账创建表单页面
