## ADDED Requirements（新增需求）

### Requirement: 选择结算单位（公司）

系统应允许用户使用现有的组织 API 选择结算单位（公司）。

#### Scenario: 搜索和选择公司

- **WHEN** 用户打开公司选择器下拉框
- **THEN** 系统显示来自组织 API 的可搜索公司列表

#### Scenario: 公司选择触发余额查询

- **WHEN** 用户选择一个公司
- **THEN** 系统获取并显示该公司的结欠余额

### Requirement: 展示结欠余额

系统应显示所选公司的结欠余额。

#### Scenario: 公司选择后展示结欠余额

- **WHEN** 用户选择一个公司
- **THEN** 系统显示结欠余额金额及币种信息

#### Scenario: 结欠余额不可用

- **WHEN** 结欠余额数据不可用
- **THEN** 系统显示适当的空状态或加载指示器

### Requirement: 选择销账明细

系统应允许用户选择要包含在销账中的明细项目。

#### Scenario: 显示可选择的明细项目

- **WHEN** 已选择公司且有可用明细项目
- **THEN** 系统显示带选择复选框的明细项目列表

#### Scenario: 计算已选金额合计

- **WHEN** 用户选择或取消选择明细项目
- **THEN** 系统实时更新已选金额合计

### Requirement: 填写销账金额和银行信息

系统应允许用户指定销账金额并选择银行信息。

#### Scenario: 指定销账金额

- **WHEN** 用户输入销账金额
- **THEN** 系统根据已选明细项目合计验证金额

#### Scenario: 选择银行信息

- **WHEN** 用户打开银行选择器
- **THEN** 系统显示来自银行 API 的银行列表及账户详情

#### Scenario: 银行选择后自动填充信息

- **WHEN** 用户选择一个银行
- **THEN** 系统自动填充银行名称和银行账户信息
- **AND** 用户可以看到填充的账户信息（只读显示）

### Requirement: 支付信息汇总展示

系统应在选择明细后显示支付信息汇总，帮助用户核对销账金额。

#### Scenario: 显示支付信息汇总卡片

- **WHEN** 用户选择结算单位并查看明细
- **THEN** 系统显示支付信息汇总卡片，包含：
  - 结欠余额（总额）
  - 已选明细合计
  - 转换后金额（外币时）
  - 销账金额

#### Scenario: 实时更新支付信息

- **WHEN** 用户选择/取消选择明细项目
- **THEN** 系统实时更新已选明细合计
- **AND** 系统计算并显示剩余余额

### Requirement: 多币种支持及汇率

系统应支持外币交易及可选的汇率计算。

#### Scenario: 外币选择

- **WHEN** 用户选择与基础币种不同的币种
- **THEN** 系统提示输入汇率信息

#### Scenario: 计算转换金额

- **WHEN** 用户输入汇率
- **THEN** 系统显示基础币种的转换金额

### Requirement: 保存销账记录

系统应保存包含所有提供信息的销账记录。

#### Scenario: 保存有效数据的销账

- **WHEN** 用户点击保存且所有必填字段已完成
- **THEN** 系统保存销账记录并显示成功消息

#### Scenario: 保存时验证错误

- **WHEN** 用户点击保存但数据缺失或无效
- **THEN** 系统显示验证错误并阻止保存

### Requirement: 销账创建的 Mock APIs

系统应提供销账创建的 Mock API 端点，直到后端对接完成。

#### Scenario: Mock 结欠余额 API

- **WHEN** 前端请求公司的结欠余额
- **THEN** 系统返回 Mock 余额数据

#### Scenario: Mock 明细项目 API

- **WHEN** 前端请求公司的明细项目
- **THEN** 系统返回 Mock 明细项目列表

#### Scenario: Mock 保存销账 API

- **WHEN** 前端提交销账数据
- **THEN** 系统返回 Mock 成功响应
